## 1.4.0 (2026-10-21) — what matters for the course

- **Compaction and branch summaries use the model's output limit.** `reserveTokens` now *only* decides when
  compaction starts ("It only decides when compaction starts. Summary requests use the model's output limit,
  reduced when needed so input and output fit the context window" — `docs/compaction.md`). SDK
  `generateSummary()` / `generateSummaryWithUsage()` ignore their `reserveTokens` parameter.
  → TECHNICAL_GUIDE §5 and the local-models guide (set a realistic `maxTokens` for small models).
- **Models Configuration reference** generated from the `models.json` schema
  (<https://pi.dev/docs/latest/models-configuration>).
- **Codemode** queues parallel scripts and in-process subagents instead of failing; `PI_CODEMODE_MAX_WORKERS`
  raises the worker limit (default: two workers per Pi process — `docs/codemode.md`). Subagents are still **not**
  built in as a user feature; the course's §9 stands.
- Extensions' `before_provider_headers` no longer see the OpenRouter / NVIDIA NIM / OpenCode attribution headers.
- Provider-level `compat` in `models.json` also applies to classifier models.
- Default model changes (GitHub Copilot, NVIDIA, Xiaomi) — not used in the course.

## 1.5.0 (2026-11-02) — what matters for the course

- **Breaking — tool argument validation moved to `@earendil-works/pi-schema`.** TypeBox features outside
  JSON Schema (`Type.Refine()`, `Type.BigInt()`, `Type.Undefined()`, codecs, `Format.Set()`) no longer apply to
  tool arguments; plain JSON Schema tools **including MCP tools** get the same coercion as TypeBox tools
  (numeric strings → numbers, a single value → array); validation errors to the model use pi-schema's format.
  → §10 `registerTool` note.
- **MCP OAuth** defaults to `oauth.clientRegistration: "auto"` (Client ID Metadata Document when supported,
  dynamic registration otherwise; `"dcr"` always registers); new `pi mcp add --oauth-client-registration`.
  → §7.
- **Native OS `sandbox/` extension example removed** (with its dependency). → §3 layer 3, Appendix A, deck
  slide "Permissions", SPEAKER_GUIDE slide "Permissions".
- **Extension update changelogs** on the next fresh launch after an update (`collapseChangelog` condenses them).
- **Self-update** through `PI_SELF_UPDATE_COMMAND` / `selfUpdateCommand` for wrappers or other package managers.
- `/model` and `/scoped-models` show a model's **name** next to its ID; the built-in catalog moved to
  **models.dev v2** (realtime and image-only models no longer offered as chat models).
- Device-code login opens the verification page and copies the code on Enter.
- `pi.exec()` gains `maxBuffer` and a `truncated` result field.
- Faster streaming for large tool calls. Default OpenAI model → `gpt-6.1-sol`.

## Unchanged (re-read in the 1.5.0 docs)

`--tools` semantics (keeps MCP tools unless an entry starts with `mcp__`), `--no-mcp`, `--approve`, context-file
rules, `/skill:name`, `defaultProjectTrust`, `compaction.*` defaults (16384 / 20000), the built-in llama.cpp
provider (`/login llama.cpp`, `/llama`, default router URL `http://127.0.0.1:9931`), `models.json` local
providers (Ollama, LM Studio, vLLM, SGLang).
